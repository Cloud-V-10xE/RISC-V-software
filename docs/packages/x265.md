# x265

x265 is the leading open-source HEVC/H.265 encoder.

## Why prebuilt for RISC-V?

x265 gained a **full RISC-V vector backend in release 4.2** (April 2026), contributed by Sanechips/ZTE. `source/common/riscv64/` now holds ~23 files covering DCT/IDCT, SAD, SATD/SA8D, intra prediction, filters, loopfilter and SAO.

Tags 4.0 and 4.1 have no `riscv64` directory at all — so **Ubuntu 24.04's x265 3.5 (tagged March 2021) contains zero RISC-V code**, and even Debian trixie's 4.1 predates the backend. Upstream publishes no binaries for any architecture.
